# JavaProjects

Repositório dedicado aos meus estudos e projetos desenvolvidos em **Java**, com foco em lógica de programação, Programação Orientada a Objetos (POO) e desenvolvimento de aplicações utilizando os principais conceitos da linguagem.

O objetivo deste repositório é registrar minha evolução no aprendizado de Java por meio de exercícios e projetos práticos.
